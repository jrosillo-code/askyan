# ASKYAN EXPEDITIONS - Design Guidelines

## Design Approach
**Premium, Rugged, Minimalist, Cinematic** - A single-page teaser website that establishes brand legitimacy through storytelling and captures email leads. Not a booking platform - this is a "digital flag in the ground" focused on brand presence and waitlist building.

## Typography System

**Display Font (Headlines/Navigation):** Inter
- Logo and navigation: Inter bold/black weights
- Hero headline: Inter 900 weight, very large scale
- Section headlines: Inter 700 weight

**Body Font (Content):** Lora (serif)
- Philosophy statement: Large, centered, serif for gravitas
- Founder descriptions: Standard body size
- All paragraph content: 1.7 line-height for readability

## Color Palette

**Background:** Very dark grey, almost black (#111111)
**Primary Text:** Off-white for readability (#EAEAEA)
**Accent/CTA:** Earthy amber/gold (#D4A373) - used for borders, buttons, highlights
**Secondary Text:** Grey for subtitles and muted content (#A1A1A1)

## Layout Structure

**Spacing:** Generous vertical padding between sections to create breathing room and cinematic pacing

**Header Navigation:**
- Fixed position at top
- Transparent background transitioning to slightly opaque on scroll
- Logo (ASKYAN text) on left
- Navigation links: "Our Philosophy," "The Founders" 
- Primary CTA button: "Join The First" in amber/gold (#D4A373) with solid background

**Hero Section:**
- Full viewport height (100vh)
- Background video (cinematic footage of remote destination)
- Dark overlay (60% black opacity) for text readability
- Centered content with headline "This Is Not A Tour"
- Subtitle: "It's an invitation to the unseen world"

**Philosophy Section:**
- Single centered paragraph with max-width for readability
- **Key Design Feature:** 3px solid amber/gold left border with padding to emphasize the core statement
- Large text size to command attention
- Generous top/bottom padding

**Command Structure (Founders) Section:**
- Headline: "The Command Structure"
- Two-column grid layout
- Each founder card includes:
  - Profile image (placeholder)
  - Name and title as headline: "Blaze - The Architect" / "Jacobo - The Pathfinder"
  - Description paragraph beneath
- Cards have slightly darker background than main page for depth
- Clean, minimal card design

**Waitlist Section:**
- Centered layout
- Headline: "Become a Founding Member"
- Supporting paragraph explaining priority access
- Email input field and submit button aligned horizontally
- Premium, clean form styling matching brand aesthetic
- Submit button in amber/gold accent color

**Footer:**
- Simple centered copyright: "© 2024 ASKYAN EXPEDITIONS. ALL RIGHTS RESERVED."

## Responsive Behavior

**Mobile (<768px):**
- Navigation collapses to hamburger menu
- Two-column founder layout stacks to single column
- Hero text scales appropriately
- Form elements stack vertically if needed

## Images

**Hero Section:** Background video element covering full viewport
- Use cinematic footage of remote, rugged landscapes
- Video should autoplay, loop, and be muted
- Show authentic expedition scenarios - not polished tourism

**Founder Profiles:** Two portrait-style images
- Professional but rugged aesthetic
- Field/outdoor settings preferred over studio shots
- Images should convey authority and adventure

## Interactive Elements

**Mobile Menu:** JavaScript toggle for hamburger icon
**Form Submission:** Prevent default, show "Thank you for joining!" confirmation
**Scroll Behavior:** Smooth scrolling to anchor sections from navigation

## Key Design Principles

- **Cinematic pacing:** Each section should feel deliberate and impactful
- **Premium restraint:** Don't overcrowd - let content breathe
- **Authentic over polished:** Rugged imagery, honest storytelling
- **Authority through minimalism:** Clean design establishes credibility
- **Story-driven:** Every element reinforces the expedition narrative
